## ✨ Key Features
* **User Grievance Submission:** Allows students and faculty to submit detailed complaints across various categories.
* **Real-Time Status Tracking:** Enables users to monitor the status of their submitted issues transparently.
* **Admin Management:** Provides a centralized dashboard for college administration to review and resolve feedback.
